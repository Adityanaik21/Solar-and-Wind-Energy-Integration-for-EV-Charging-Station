# Hybrid Solar and Wind Energy Integration for EV Charging Station

## Project Overview

This project presents a MATLAB/Simulink model for integrating solar photovoltaic (PV) and wind energy sources for supplying an electric vehicle (EV) charging station.

The system combines renewable energy sources to provide a reliable and sustainable power supply for EV charging.

## Objectives

- Integrate solar PV and wind energy sources.
- Develop a hybrid renewable energy system in MATLAB/Simulink.
- Supply power to an EV charging station.
- Study the power flow between renewable sources, the grid, and EV charging.
- Analyze the performance of the integrated system.

## System Description

The proposed system consists of:

- Solar PV generation system
- Wind energy generation system
- Power electronic converters
- DC/AC inverter
- EV charging station
- Grid connection
- Control and monitoring system

## Solar Energy

The solar PV system converts solar energy into electrical energy. The generated power is processed through power electronic converters before being supplied to the charging system.

## Wind Energy

The wind energy conversion system generates electrical power from wind energy. The generated power is integrated with the solar PV source to form a hybrid renewable energy system.

## EV Charging

The hybrid renewable energy system supplies power to the EV charging station. The system can utilize available renewable power and grid power to meet the charging demand.

## Software Used

- MATLAB
- Simulink
- Simscape Electrical


## How to Run

1. Download or clone this repository.
2. Open MATLAB.
3. Set the repository folder as the MATLAB current folder.
4. Open `Hybrid_Solar_Wind_EV_Charging.slx`.
5. Run the Simulink model.
6. Observe the simulation results.
